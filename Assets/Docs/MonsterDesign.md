## 2. 通用属性规则

### 2.1 属性推断规则

| 属性 | 推断规则 |
|---|---|
| moveType | 描述含"飞行" → Fly，否则 Ground |
| attackType | 描述含"远程/射击/投掷/射线/吐息" → Ranged，否则 Melee |
| attackRange | Ranged: boss=220, 普通=160; Melee: 42 |
| moveSpeed | Fly: 72, Boss: 48, 普通: 58 |
| attackInterval | Ranged: 1.1s, Melee: 0.85s |
| radius | Giant(3个): 56, Boss: 28, Fly: 16, 普通: 18 |
| armorToughness | 默认 0（仅 Boss 有护甲韧性时设置） |

### 2.2 标签系统

| 标签 | 触发关键词 | 效果 |
|---|---|---|
| `boss` | 描述含"boss" | 体量更大，通常有独立技能 |
| `fly` | 描述含"飞行" | 飞行单位 |
| `arthropod` | 描述含"节肢"或 ID 含 spider/beetle/centipede | 节肢生物 |
| `explosive` | 描述含"自爆" | 自爆单位 |
| `aoe_melee` | 描述含"范围攻击" | 近战附带 AOE |
| `meteor_passive` | 描述含"陨石" | 被动陨石雨 |
| `fire_immune` | 描述含"火焰免疫/岩浆/陨石" | 免疫燃烧 |
| `summoner` | 描述含"召唤" | 可召唤随从 |

### 2.3 命中附带状态推断

| 状态 | 触发关键词 |
|---|---|
| poison（中毒） | 中毒/毒性/剧毒/毒液/辐照 |
| burn（燃烧） | 火焰/烈焰/点燃 |
| wither（凋零） | 凋零 |
| slow（减速） | 减速/迟缓/寒冰/冰雪/冰冻/控制 |

### 2.4 体量尺寸

| 类别 | 显示尺寸(px) | 碰撞半径(px) | 判定 |
|---|---|---|---|
| Giant | 112 | 56 | 3个: 撼地斯拉、暝煌龙、远古遗魂 |
| Boss | 56 | 28 | 所有 boss 级怪物 |
| Fly | 40 | 16 | 飞行单位 |
| Normal | 40 | 18 | 普通地面单位 |

### 2.5 命中检测半径补偿

| 场景 | 半径补偿系数 |
|---|---|
| AOE 伤害 | `radius + target.radius × 0.5` |
| 珊瑚跃击落地 | `radius + target.radius × 0.45` |
| 交战距离 | `range + target.radius × 0.5` |
| 投射物命中 | `target.radius + 6` |
| 光束命中 | `halfWidth + target.radius` |

### 2.6 对空规则

| 单位类型 | 近战攻击 | 远程攻击 | 说明 |
|---|---|---|---|
| 飞行单位 | ✅ 可对空 | ✅ 可对空 | 所有飞行单位的攻击均可对空 |
| 地面远程单位 | — | ✅ 可对空 | 大多数地面远程攻击可对空 |
| 地面近战单位 | ❌ 不可对空 | — | 地面近战不能攻击飞行单位 |

**例外**（会在怪物设计中明确标注）：
- 部分地面近战 Boss 的特定技能可对空（如末影傀儡的虚空符文）
- 部分地面技能标注为"仅地面单位"（如骸骨斩首者的所有技能、炽燃遗魂的旋转）
- 飞行近战单位攻击时会设置 `vulnerableWindow = 0.55s`，在此窗口内地面近战可以反击

#### 技能

**① AOE 践踏（普攻）**
- 类型：AOE 近战
- 半径：80 px
- 伤害：30（=攻击力，melee 类别）
- 间隔：1.0 s
- 动画：0.4 s
- 冲击波视觉效果

**② 超能射线（主动技能）**
- 类型：持续光束
- 持续时间：5 s
- 刻数：15 tick
- 刻间隔：0.333 s（5÷15）
- 每刻伤害：20（beam 类别）
- 总伤害：300
- 射程：500 px
- 半宽：24 px
- 施法距离：280 px（目标在此距离内才会释放）
- 冷却：20 s

#### AI 逻辑

```
if 目标在施法距离(280)内 && 光束冷却完毕(30s):
    释放超能射线
else:
    AOE 践踏（普攻）
```

- 交战半径 = max(58, 280) = 280
- 光束持续期间处于 channeling 状态，不能移动

#### 特殊机制
- Giant 体量（半径 56），AOE 范围极大（92）
- 光束总伤害 300，约为普攻的 10 倍
- 辐照（poison）附带效果

| 属性 | 值 | 备注 |
|---|---|---|

| 攻击间隔 | 2.2 s | |
| 碰撞半径 | 56 px | Giant |

| 攻击类型 | Melee | |
| 标签 | boss, lux_boss, giant, fire_immune, meteor_passive | |
| 命中附带 | burn（点燃） | |

#### 技能

**① 跃击**
- 类型：跳跃 + AOE
- 触发条件：距离 > 100 且 ≤ 340 且冷却完毕
- 跳跃时长：0.84 s
- 弧高：55 px
- 落地 AOE 半径：48 px
- 落地伤害：12（melee）
- 附带 burn
- 冷却：10 s
- 跳跃用抛物线插值（ease = t×(2-t)）

**② 甩尾**
- 类型：自身周围 AOE
- 半径：112 px
- 伤害：12（melee）
- 附带 burn
- 动画：0.7 s
- 释放后设置 luxNextStomp = true（下次用践踏）

**③ 践踏**
- 类型：目标位置 AOE
- 半径：96 px
- 伤害：12（melee）
- 附带 burn
- 动画：0.7 s
- 释放后设置 luxNextStomp = false（下次用甩尾）

**④ 陨石雨（被动）**
- 类型：自动施放
- 间隔：3 s
- 陨石生成范围：自身周围 200 px 内随机位置
- 下落时间：0.55 s
- 爆炸半径：53 px
- 爆炸伤害：20
- 爆炸目标：所有单位（含飞行）
- 附带 burn
- 生成熔岩区域

**⑤ 熔岩区域**
- 半径：53 px
- 持续：30 s
- DPS：5
- 附带 burn
- 仅对地面非 fire_immune 单位造成伤害
- 每 1 s 结算一次

#### AI 逻辑

```
if 距离 > 100 && 距离 ≤ 340 && 跃击冷却完毕:
    跃击
elif 在近战范围内:
    if luxNextStomp: 践踏
    else: 甩尾
    （交替使用）
```

- 交战半径 = max(55, 340) = 340

#### 特殊机制
- fire_immune：熔岩和燃烧对其无效
- meteor_passive：每 3 秒自动召唤陨石
- 甩尾和践踏交替使用
- 移速极慢（24），但跃击可快速接近
- 所有 AOE 伤害附带点燃

- 石碑弹幕从中心向外环形扩散
- 可以排队下一个技能（remnantQueuedSkill）

- 8 颗手雷
- 每颗伤害 20，爆炸半径 58
- 散布半径 200（自身周围随机位置）
- 附带 wither

- 附带 burn
- 每帧追踪目标方向
- kind = 'harbinger_death'

#### AI 逻辑

```

特殊技能: 每 5s 释放一个，循环 [homing_missiles → grenades → charge → death_laser]
```

- 交战半径 = 240
- 特殊技能索引 (harbSkillIndex) 每次释放后 +1，mod 4

#### 特殊机制
- 飞行远程 Boss
- 模式切换 + 技能循环，非常复杂
- 死亡射线是持续光束，穿透所有敌人
- 追踪导弹有转向行为
- 冲撞用线段碰撞检测

#### 身体结构（多体节）

娜迦是一只贪吃蛇形态的长条生物，由许多方形体节连接组成。

**体节定义：**
| 参数 | 值 | 说明 |
|---|---|---|
| 头部 | 唯一可选中/受伤部位 | 攻击判定和伤害结算的唯一目标 |
| 体节数量 | 3-8 节（随血量动态变化） | 满血 8 节，最低 3 节 |
| 体节间距 | 16 px | 相邻体节中心距离 |
| 体节尺寸 | 12×12 px | 每节方形碰撞体 |
| 体节跟随 | 平滑链式跟随（每节追随前一节位置） | 类似贪吃蛇 |

**体节判定规则：**
- **头部**：可被敌方选中为目标，可受到伤害，有 HP 判定
- **体节**：**不可被选中**，**不受到伤害**，但**会造成接触伤害**
- 敌方攻击只能锁定头部（目标选择时过滤掉体节）
- 投射物/光束碰到体节不会命中（不造成伤害，不阻挡弹道）
- 敌方单位碰到任意体节（含头部）都会受到娜迦的接触伤害

**体节数量随血量变化：**
- 满血（100%）时 8 节
- 血量降低时逐渐减少，最低 3 节
- 公式：`体节数 = clamp(round(3 + 5 × hp / maxHp), 3, 8)`
- 断尾时最末端的体节直接消失（不做特殊视觉效果，后续可设计断尾动画）

**接触伤害冷却：**
- 所有体节（含头部）**共享一个** 0.5 s 的接触伤害冷却
- 即：0.5 s 内只有一次接触伤害生效，无论哪个体节碰到、碰了几个敌人
- 冷却结束后任意体节接触敌人即可再次触发

**体节跟随算法：**
```
每帧更新:
    头部按蛇形移动逻辑移动
    体节[0] → 平滑追随头部位置（保持间距 16px）
    体节[i] → 平滑追随体节[i-1] 位置（保持间距 16px）
    平滑系数：lerp factor = min(1, dt * 20)
    转弯时体节自然弯曲（每节位置基于前一节方向偏移）
```

#### 技能

**① 接触伤害（所有体节 + 头部，共享冷却）**
- 任意体节（含头部）碰到敌人时造成 6 伤害（melee）
- **所有体节共享一个 0.5 s 冷却**（0.5s 内仅触发一次，无论哪个体节碰到）
- 触发距离 = 体节半径(12) + target.radius + 4

**② 蛇形移动**
- 选择目标身后 100 px 的点作为移动目标
- 附加垂直随机偏移 60 px
- 重选间隔 1.2 s × 随机(0.7-1.3)
- 速度随 HP 降低而提升：speed = moveSpeed × (1 + (1.5-1) × (1 - hp/maxHp))
- 体节链式跟随头部

#### AI 逻辑
使用自定义 `tickNaga()` 替代标准战斗系统，包含头部移动 + 体节链更新。

#### 特殊机制
- **多体节结构**：只有头部可被选中/受伤，体节不可被选中但造成接触伤害
- **不使用标准目标选择和攻击系统**
- 蛇形穿梭移动，所有体节均造成接触伤害
- 速度随 HP 降低提升（最高 1.5× = 120）
- 体节数量可随长度变化（未来可设计断尾机制）
- **视觉**：当前为单个 PNG 文件，后续需重新设计为头部 + 体节精灵的程序化拼接
