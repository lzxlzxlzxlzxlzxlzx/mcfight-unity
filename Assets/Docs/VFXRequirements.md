# 战斗视觉特效需求清单

> 用于下一阶段制作更好的动画效果

## 一、投射物类（飞行中的弹道）

### 1.1 通用远程投射物
- **形状**：箭矢/小弹丸
- **效果**：拖尾（蓝/红队伍色）
- **当前**：4x4 纯色方块
- **目标**：三角形箭矢 + 渐变拖尾

### 1.2 先驱者追踪导弹 (HarbHoming)
- **形状**：紫黑色球体
- **效果**：紫色螺旋拖尾 + 命中爆炸（半径42px 紫色光圈）
- **当前**：紫色方块 + 线性拖尾

### 1.3 先驱者激光弹 (HarbLaser)
- **形状**：红色细长光束
- **效果**：红色直线拖尾 + 高速移动模糊感
- **当前**：红色小方块

### 1.4 炽燃遗魂骨弹 (RevenantBone)
- **形状**：骨头形状
- **效果**：白色拖尾 + 命中碎裂效果
- **当前**：灰白色方块

### 1.5 遗弃者弧形声波 (ForsakenSonic)
- **形状**：弧形带状波纹
- **效果**：青色半透明弧波 + 穿透不消失
- **当前**：青色大方块（无弧形感）

### 1.6 冰球 (IceBomb)
- **形状**：蓝白色冰晶球
- **效果**：冰雾拖尾 + 落地爆炸（碎冰飞溅）
- **当前**：蓝色方块

### 1.7 徘徊者导弹 (ProwlerMissile)
- **形状**：紫红色导弹
- **效果**：尾焰拖尾 + 追踪轨迹 + 命中爆炸（半径24px）
- **当前**：紫色方块

### 1.8 烈焰人烈焰球
- **形状**：橙红色火球
- **效果**：火焰拖尾 + 随机偏移弹道 + 命中燃烧效果
- **当前**：默认方块

### 1.9 娜迦(飞行)剧毒射击
- **形状**：绿色毒液弹
- **效果**：绿色拖尾 + 命中毒雾扩散
- **当前**：默认方块

### 1.10 深潜者法师水弹
- **形状**：蓝色水球
- **效果**：水雾拖尾
- **当前**：默认方块

### 1.11 唤魔者尖牙
- **形状**：从地面冒出的尖牙（近距圆圈/远距直线）
- **效果**：地面裂开动画 + 尖牙升起 + 消散
- **当前**：无视觉（即时伤害）

- **当前**：红色矩形

### 2.3 徘徊者死亡射线 (ProwlerRay)

## 三、近战/AOE 范围展示

### 3.1 通用近战攻击
- **效果**：攻击瞬间在目标位置显示命中标记（十字/X 标记，快速淡出）
- **当前**：无视觉

### 3.2 通用 AOE 近战（擎天龙/炽燃狂魂等）
- **形状**：以攻击者为中心的圆形扩散波
- **效果**：冲击波从中心向外扩散 + 淡出 + 队伍色
- **当前**：纯色圆（有渐变但单调）

### 3.3 撼地斯拉 AOE 践踏
- **形状**：以目标为中心，半径92px
- **效果**：地面龟裂 + 毒绿色波纹扩散 + 附带辐照粒子
- **当前**：蓝色圆形

### 3.4 暝煌龙甩尾（半径112px）/ 践踏（半径96px）
- **形状**：自身周围大范围
- **效果**：火焰环扩散 + 熔岩残留 + 燃烧粒子
- **当前**：蓝色圆形

### 3.5 暝煌龙陨石（被动）
- **形状**：从天而降的火球
- **效果**：下落轨迹 + 落地爆炸（半径53px）+ 生成熔岩区域
- **当前**：无独立视觉

### 3.6 暝煌龙熔岩区域
- **形状**：圆形持续区域（半径53px，持续30s）
- **效果**：橙红色岩浆纹理 + 冒泡粒子 + 5DPS
- **当前**：橙红色半透明圆

### 3.7 骸骨斩首者三连斩

  - **效果**：刀光弧线 + 火花飞溅
- **Strike 3 终结**：圆形 AOE（半径72px）
  - **效果**：重击冲击波 + 地面裂痕
- **当前**：无视觉（即时伤害）

### 3.8 骸骨斩首者践踏
- **形状**：锥形（长度224px，角度38°）
- **效果**：地面震荡波 + 沿锥形方向扩散
- **当前**：无视觉

### 3.9 骸骨斩首者冲锋

- **效果**：残影轨迹 + 落地冲击波（半径72px）+ 尘土飞扬

### 3.10 末影傀儡猛击（半径72px）

- **当前**：无视觉

6. 深潜者法师水波扇形
7. 锥形喷射效果（寒冬狼/喷火甲虫）

### P1（提升视觉质量）

9. 光束粒子效果（撼地斯拉/先驱者/徘徊者）
10. AOE 冲击波美化
11. 陨石下落动画
12. 沙暴龙卷风3D感
13. 瓦吉特龙卷穿透效果

### P2（细节增强）
